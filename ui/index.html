Cómo usarlo en Discord

Configuración en menos de un minuto.

  1. Instala un cable virtual gratis (VB-Cable).
  2. Aquí, elige el cable en Salida y pulsa INICIAR.
  3. Discord → Ajustes → Voz y vídeo → Entrada: CABLE Output.
  4. Desactiva la supresión de ruido de Discord para que no borre los efectos.
